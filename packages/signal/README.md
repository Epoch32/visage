# signal

> Micro-cell reactive primitive with non-allocating subscriber sets and atomic write transactions for fine-grained state tracking.

**Part of the [Epoch32](https://github.com/Epoch32) sequence (Track 2, Week 01).**

## Features

- **Zero External Dependencies**: Pure TypeScript native implementation.
- **Edge-First**: Compatible with Cloudflare Workers, Fastly, Bun, Deno, Node.js, and modern browsers.
- **Formally Pinned**: Verifiable Known-Answer Test (KAT) vector test suite.

## Installation

```bash
bun add @epoch32/signal
```
